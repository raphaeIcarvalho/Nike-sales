# 📱 Painel de Vendas - Dashboard de Tênis da Nike

Este projeto é um painel de controle (dashboard) focado na organização, análise e visualização de dados de vendas de diferentes modelos de tênis da marca Nike. O objetivo principal é fornecer uma comparação clara entre os modelos e a quantidade de vendas de cada um deles.

## 🛠️ Tecnologias Utilizadas

Abaixo estão as tecnologias e ferramentas empregadas no desenvolvimento do projeto:

* **Software:** Excel (Microsoft 365)
